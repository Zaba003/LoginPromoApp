# Контракты

В эту папку попадут: DTO API, JSON Schema метаданных, схема событий интеграции и versioned compatibility tests. Контракты не должны импортировать Cordis и не содержат SQL или HTTP реализации.

Пример в `examples/`: разделяет схему данных формы, UI схему и правила сводного отчёта. Примеры не являются регламентом какого-либо органа.
