# Правила разработки для AI-агентов и команды

1. Прежде чем менять архитектуру — прочитай README, `docs/02-architecture.md`, ADR.
2. **Не** соединять приложение напрямую с Pulse DB, не внедрять зависимость от Pulse runtime.
3. **Не** писать новые плагины на каждый отчёт или государственный орган: это данные и версии конфигурации.
4. **Не** изменять опубликованные версии форм/правил/утверждённых данных в БД; создавать новые версии.
5. Любой доступ к отчёту проверять по actor + action + resource scope; только UI-проверки недостаточны.
6. Любой статусный переход — транзакция с аудитом и outbox, покрытая тестом.
7. Worker должен быть идемпотентным. Нельзя полагаться на exactly-once.
8. Схемы форм — JSON Schema; пользовательский код/eval/scripts в формах запрещены.
9. Не подключать CDN, телеметрию или внешние сервисы в закрытом контуре.
10. Предложение заменить Cordis допускается только через ADR после технического spike.
11. Не выдавать архитектурный starter за готовый продукт и не заявлять о прохождении ИБ аудита.
