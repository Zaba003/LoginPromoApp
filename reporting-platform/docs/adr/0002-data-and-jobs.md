# ADR-0002: PostgreSQL + очередь в PostgreSQL

- **Дата:** 2026-11-11
- **Статус:** proposed

Для on-prem MVP выбрать PostgreSQL как источник истины и pg-boss для фоновых задач, уведомлений и scheduled jobs. Это снижает количество инфраструктурных компонентов по сравнению с Redis/BullMQ. Возможность заменить очередь оставить за интерфейсом `JobQueue`.

Не использовать очередь как единственное хранилище бизнес-состояния: расписание отчётных кампаний, задания и дедлайны должны храниться в доменной БД. Очередь обеспечивает доставку/повторное исполнение. Idempotency keys и outbox — обязательны.

Условия пересмотра: новая нагрузка/изолированные кластеры/особые гарантии доставки.
