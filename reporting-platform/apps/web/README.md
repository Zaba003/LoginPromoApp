# Web-клиент (план)

Здесь будет React + TypeScript + Vite. Пока не добавлен, чтобы не подменять согласование UX стандартной админкой.

Первый экран — рабочий стол исполнителя: мои задания/сроки/статусы. Далее: ввод формы, замечания, история. Для координатора — кампании, просроченные задания, сводные отчёты; для методолога — конструктор форм и показателей.

Дизайн — единая система компонентов. Позднее можно использовать фирменные токены Pulse, но клиент должен полноценно работать отдельно от него.
